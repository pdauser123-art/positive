## 四、零經驗手把手教學：如何免費上架到 GitHub Pages（免打指令、免綁信用卡）

你完全不需要使用終端機或寫程式指令，只要用瀏覽器照著以下 **5 個步驟** 點擊，約 **3 分鐘** 就能擁有專屬的免費網站網址：

### 第一步：註冊並登入 GitHub 帳號

1. 前往 [GitHub 官方網站](https://github.com/)。

2. 若還沒有帳號，點擊右上角 **Sign up** 免費註冊一個帳號（已註冊請直接點 **Sign in** 登入）。

### 第二步：建立一個新的專案倉庫 (Repository)

1. 登入後，點擊畫面右上角的 **「＋」號圖示**，選擇 **New repository**（建立新倉庫）。

2. 在 **Repository name**（倉庫名稱）欄位，輸入英文名稱，例如：`positive-to-the-end`。

3. 確認下方權限選擇 **Public**（公開，這樣才能免費使用 GitHub Pages 網站服務）。

4. 直接滑到最下方，點擊綠色按鈕 **Create repository**。

### 第三步：用滑鼠拖曳上傳檔案

1. 建立完成後，在畫面中間找到藍色字連結 **uploading an existing file**（上傳既有檔案），點進去。

2. 先在你的電腦上把我們準備好的 `positive_to_the_end_project.zip` **解壓縮**，打開裡面的 `positive_to_the_end` 資料夾。

3. 把資料夾裡面的檔案（特別是 **`index.html`**、**`README.md`**、**`.nojekyll`**、**`.gitignore`**、**`LICENSE`**）用滑鼠全選，直接**拖曳到 GitHub 網頁的框框裡**。

4. 等檔案列表跑出來後，滑到網頁最下方，點擊綠色按鈕 **Commit changes**（儲存變更）。

### 第四步：開啟 GitHub Pages 免費網站開關

1. 上傳成功後，點擊專案頁面上方導覽列的 **Settings**（齒輪圖示「設定」）。

2. 在左側選單找到 **Pages**（位於 Code and automation 區塊下方），點進去。

3. 在 **Build and deployment** 下方的 **Branch**（分支）設定處，把原本顯示 `None` 的下拉選單改選為 **`main`**（或 `master`），旁邊的資料夾維持 **`/ (root)`**，然後點擊 **Save**（儲存）。

### 第五步：取得你的專屬網站網址！

1. 點擊 **Save** 後，等待約 **1 到 2 分鐘**，重新整理（F5）這個 Pages 設定頁面。

2. 頁面上方就會出現一行提示：**Your site is live at `https://你的帳號.github.io/positive-to-the-end/`**。

3. 點擊這個網址，就能在手機或電腦打開「**正向♥️正向到底**」，也能把網址分享給朋友或放在社群簡介上！

## 五、常見問題（FAQ）

### 1. 我的個人 Gemini Pro (Gemini Advanced) 訂閱到期後，網站還能用嗎？

**完全可以，100% 不受影響！**
你目前的個人 Gemini Pro 訂閱只是用來在聊天室裡請我幫你寫程式；一旦我們把網站檔案做好並放到 GitHub Pages 上，網站就是獨立運作的程式碼，跟你的個人 Gemini 訂閱毫無綁定關係。就算訂閱到期，網站依然可以永久免費開啟、轉換文字、寫金句與下載圖卡。

### 2. 放在 GitHub Pages 上會不會突然收到帳單？

**不會。** GitHub Pages 對公開專案（Public Repository）提供永久免費託管，甚至不需要輸入信用卡號；而且我們的網站已預設採用「內建溫柔轉換規則庫＋本機瀏覽器儲存」，不會去呼叫任何按量計費的外部雲端資料庫或付費 AI API，因此產生費用的機率是 **0%**。

### 3. 日後如果想修改網站上的文字，該怎麼更新？

只要回到你的 GitHub 專案頁面，點進 `index.html`，點擊右上角的「✏️ 鉛筆圖示（Edit this file）」，修改文字後按下右上角綠色的 **Commit changes**，等待 1 分鐘網站就會自動更新完成！
